# Provenance and compatibility

The baseline is the Human20 workshop SEO/AEO/GEO Principal+ package, name
seo-aeo-geo-principal version 1.0.0, MIT/public-clean export.

The user-supplied October 4, 2026 archive contains a Chip derivative, chip-seo-geo-aeo
version 2.0.0. Its provenance describes a reconstruction of the baseline and independently
implemented patterns; it is not a byte-identical original archive. Preserve its MIT notice.
No external optimizer implementation is vendored.

This merged version preserves the original skill name and CLI commands. It incorporates
bounded sitemap-index traversal, robots-purpose observations, HTTP noindex, content
extraction hints, explicit snapshots, per-dimension comparisons and optional MCP.

The installed copy's pacing and abort controls are retained. Loopback preview is an explicit
CLI opt-in. Optional llms/agent endpoint status no longer affects readiness scoring; synthetic
measurements cannot become real performance evidence. Browser selection follows the host's
available tools. No Chip profile, operator-specific output format or relay is required.

The model is 2.2-principal-merged. Before/after comparison recomputes both records under
this model; differing samples and incomplete crawls are reported as warnings.
